# Projects

## Creating a project
Open the Projects page and click the New project button. Enter a project name and choose a status, then press Create. Project names must be unique within your workspace and can be up to 80 characters.

## Project status
Every project has a status: Planning, Active or Done. Change the status from the status menu on the project row. Done projects stay visible but are moved to the bottom of the list.

## Archiving and deleting
Projects can be archived from the project row menu. Archived projects are read-only and hidden from the Dashboard. Only workspace admins can permanently delete a project, and deletion cannot be undone.

## Permissions
Members with the Editor or Admin role can create and edit projects. Viewers can see projects but cannot change them.
