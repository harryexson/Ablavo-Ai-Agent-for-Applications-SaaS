# Getting started with Lumen Projects

Lumen Projects helps small teams plan work in projects, track tasks and keep everyone aligned.

## Your first five minutes
1. Complete your profile from the Settings page so teammates recognize you.
2. Create your first project from the Projects page using the New project button.
3. Invite a teammate from the Team page with the Invite member button.
4. Turn on weekly digest emails in Settings if you want a Monday summary.

## Navigation
The left sidebar links to Dashboard, Projects, Team and Settings. The Dashboard shows project counts and recent activity.
